## 🎉 二次开发

1. 拉取代码

```bash
git clone https://github.com/zhanzhicai2/AIFullStackTesting.git
cd AIFullStackTesting/frontend
```

2. 安装依赖

```bash
npm install
```

3. 启动后端(参见 [backend/README.md](../backend/README.md))

4. 修改 `config/defaultSettings.ts`

按需调整 `API` / `WS` 地址,默认指向 `http://localhost:7777`。

5. 启动开发服务器

```bash
npm run start:dev
```

打开浏览器 `http://localhost:8000`,登录即可使用。
